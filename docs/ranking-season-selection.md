# 활동 랭킹 시즌 선택

- 랭킹을 처음 열면 한국 날짜 기준으로 오늘이 기간에 포함되고 상태가 `active`인 시즌을 선택한다.
- 현재 시즌을 선택 목록의 첫 항목에 표시하고 이름 옆에 ‘현재 시즌’을 붙인다.
- 겹치는 진행 시즌이 있으면 시작일이 더 최근인 시즌을 우선한다.
- 현재 시즌이 없으면 전체 시즌을 표시한다.
- 전체 시즌은 `seasonId=all`로 명시적으로 조회하며 날짜 필터 없이 전체 기간을 집계한다.
- 과거 시즌 등 특정 시즌을 직접 선택하면 해당 선택을 유지한다.
- 이전 전체 집계용 ‘기본 시즌’ 항목(`is_default=true`, 이름 ‘기본 시즌’)은 랭킹 선택 목록에서 전체 시즌으로 통합한다. 기존 ID로 접근해도 전체 기간을 표시한다. DB의 시즌 이름·기록은 변경하지 않는다.
- 비공개·숨김 시즌 조회 권한은 기존대로 유지한다.

활동 랭킹 페이지와 통계 API에 같은 규칙을 적용한다. 추가 SQL 적용은 필요 없다.

선택·전체 기간·한국 날짜 경계·중복 시즌을 포함한 릴리스 테스트 40개가 통과했다.

## 시즌 삭제

시즌 관리에서 해당 시즌을 펼치고 하단의 ‘시즌 삭제’를 누릅니다. 시즌 이름과 삭제 범위를 확인한 뒤 삭제합니다. 현재·기본 집계 시즌은 삭제 시 추가 안내를 표시하며, 다른 시즌이 자동으로 현재 시즌으로 지정되지는 않습니다.

시즌 설정 한 건만 삭제하고 일정·출석 기록은 유지합니다. 기존 시즌 설정 권한과 동일하게 활성·승인된 관리자와 회장이 삭제할 수 있습니다. 삭제 실패 시 목록을 유지하며, 성공 시 제거하고 서버 목록을 새로 불러옵니다. 기존 시즌을 참조하는 DB 기록이 있어 외래키가 삭제를 거부하면 자동으로 연쇄 삭제하지 않습니다. 추가 SQL 적용은 필요하지 않습니다.

검증: `npm run test:season-delete`는 API 권한·origin·입력·확인 값·시즌 ID 범위·외래키 거부·없는 시즌, 모바일 브라우저의 확인 취소·실패 유지·재시도 성공·현재/기본 시즌 안내를 검사합니다. TypeScript와 변경 파일 ESLint 확인. 운영 데이터 삭제나 배포는 수행하지 않았습니다.
