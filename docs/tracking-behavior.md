## 공식 거리와 GPX 길이
공식 거리는 진행 거리·페이스·예상 완주 계산의 기준이다. GPX 좌표를 순서대로 연결해 구한 누적 길이는 지도상의 배치 기준이다.

GPX 위 거리 = 공식 기준 예상 거리 × GPX 누적 길이 ÷ 공식 거리

공식 거리의 50%를 진행하면 GPX 누적 거리의 50% 위치에 표시된다. GPX에서 그 위치가 들어가는 두 좌표를 이진 탐색하고 두 좌표 사이를 보간한다. 결승점은 GPX 마지막 좌표와 일치한다.

현재 데모는 공식 21.0975km, GPX 누적 약 21.655332km로 약 2.644% 차이가 난다. 공식 기준 10km는 GPX 위 약 10.264407km에 해당한다. 길이가 다르더라도 GPX 경로 자체가 올바르다는 전제다. 누락·중복·잘못된 경로를 비례 보정으로 복구하지는 않는다. 등록 시 차이가 5%를 넘으면 확인 안내를 표시하며 자동으로 공식 거리를 바꾸지 않는다.

## 위치 예측 알고리즘
1. 초기 페이스 우선순위: 목표 완주 시간 → 목표 페이스 → 그룹 페이스 → 기본 6분/km.
2. 현재 시각까지 수신된 유효한 통과 기록만 사용한다. 중복, 미래 시각, 역순, 범위 밖 거리, 비현실적 구간 속도는 제외한다. 구간 페이스는 유효한 두 실측 지점 사이에서 계산한다.
3. 최근 최대 3개 실측 구간 페이스에 최신부터 50%·30%·20% 가중치를 둔다. 구간이 1~2개면 존재하는 가중치 합으로 정규화한다.
4. 예상 거리 = 마지막 계측 거리 + 마지막 통과 이후 시간 ÷ 최근 초/km 페이스 × 1000. 공식 코스 길이 안으로 제한한 뒤 GPX 경로에 배치한다.
5. 예상 완주 소요 = 마지막 계측까지의 소요 + 남은 공식 거리(km) × 최근 초/km 페이스. 실제 START가 없으면 예정 출발 기준이며 실제 넷타임으로 확정하지 않는다.
6. 최근 계측이 5분 이내면 HIGH, 15분 이내면 MEDIUM, 이후 LOW다. 실측 구간이 없으면 LOW다. 마지막 실측/초기 추정 이후 45분이 지나면 무한히 전진하지 않고 stale 상태로 멈추며 완주 예측도 숨긴다.
7. FINISH 실측이 있어야 완주로 확정한다. 예상으로 결승에 도달한 상태는 완주 계측 대기다. DNF는 마지막 계측 위치에서 멈추고 DNS는 출발점에 둔다.

버스의 최근 정류장 통과와 구간 속도로 다음 도착을 예측하는 방식에 대응한다. 여기서 정류장은 계측 지점, 도로는 GPX 경로, 속도는 최근 실측 페이스다. 새 기록이 들어올 때 보정된다. 현재 운영 데이터는 수동 계측 입력, 데모는 가상 계측이며 GPS 연속 수집이나 자동 계측 장비 연동은 구현돼 있지 않다. 현재 화면은 완주 예측을 표시하며 다음 5km/급수대별 ETA 화면을 새로 구현한 것은 아니다.

향후 특정 지점 도착을 표시하려면 그 지점의 공식 거리와 GPX 위치를 등록하고 남은 거리 × 최근 페이스로 ETA를 계산할 수 있다. 실제 계측 지점과 GPX 위치를 구간별로 연결하면 전체 경로 비례 보정보다 구간 편차를 줄일 수 있다. 코스 고저차·급수·정체 등 추가 요인은 아직 모델에 포함하지 않았다.

## 검증
- 실제 변경 전 소스를 같은 Chrome 모바일 터치 테스트에 넣어 한 손가락 스크롤 실패와 확대 중 표시 오차 약 543.83px를 재현했다. 테스트 위치 식별용 클래스만 추가했으며 표시 동작은 변경하지 않았다.
- 변경 후 Chrome 모바일 에뮬레이션: 한 손가락 문서 스크롤/지도 중심 불변, 두 손가락 확대·이동, 마우스 이동, 확대 중 선수 표시 오차 약 1.9px, 이동 중 보이는 GPX 좌표의 95% 이상이 그려진 stroke 안에 있는지, 새 영역 타일 요청, 크기 변경 후 줌 유지 검사 통과.
- 타일은 고정 테스트 이미지로 대체했다. 실제 OSM 통신 품질, iPhone Safari 및 Android 실기기는 별도 확인이 필요하다.
- 추적 엔진·검증 테스트 31개 통과. 공식 거리보다 짧거나 긴 GPX에서 중간 지점/예상 거리/결승점 매핑을 추가 검증했다. 위치 예측 수식 자체는 이번에 변경하지 않았다.
- 프로덕션 빌드, ESLint, TypeScript 통과. DB 마이그레이션은 추가하지 않았다. 원격 배포는 수행하지 않았다.
- 브라우저 테스트 준비: npm install --prefix .test-output/map-qa --no-save @playwright/test esbuild. 실행: npm run test:tracking-map-browser. Windows Chrome/Edge를 자동 탐색하며 다른 경로는 CHROME_PATH로 지정한다. 해당 브라우저가 없으면 Playwright Chromium 설치가 필요하다.
