# 활동 랭킹과 테스트 미리보기

## 표시 기준
- 1~3위: 시상대. 4~10위: 목록.
- 로그인한 사용자가 11위 이하일 때만 중간 생략 표시 뒤 본인 순위를 추가한다.
- 집계 대상이 아닌 사용자는 순위를 임의로 만들지 않는다.
- 닉네임이 있으면 닉네임 아래에 이름을 작은 보조 글씨로 표시하고, 없으면 이름만 표시한다.
- 점수 계산, 동점 정렬, 시즌 및 집계 제외 조건은 기존대로 유지한다.
- 일정 댓글은 현재 작성자의 이름을 표시한다. 탈퇴 등으로 프로필이 없으면 작성 당시 저장된 이름을 사용한다.

## DB와 분리된 화면 테스트
프로젝트 폴더에서 `node scripts/preview-responsive.mjs` 실행 후 http://localhost:3101/ranking 에 접속한다.
가상 회원 36명과 본인 24위가 표시된다. 실제 계정이나 출석 데이터는 생성하지 않는다.
이 서버는 화면 검증용이며 로그인, 신청, 출석 저장은 동작하지 않는다.
종료는 실행한 터미널에서 Ctrl+C. DB에 데이터가 남지 않으므로 데이터 삭제가 필요 없다.

## 실제 기능을 확인하는 테스터 환경
로그인·신청·출석까지 확인하려면 별도 Supabase 프로젝트와 별도 환경 변수를 사용한다.
운영 데이터와 분리한 프로젝트에 마이그레이션을 적용하고, 테스트 전용 계정과 일정·참가·출석 데이터를 준비한다.
테스트 계정은 기본 랭킹에서 제외되므로 랭킹 시나리오의 가상 계정은 테스트 환경에서만 집계 설정을 조정해야 한다.
테스트 환경은 아직 생성하거나 연결하지 않았다. 현재 작업은 로컬 화면 테스트 데이터까지 포함한다.
