# 출석 시작 시각 제한

일정의 `start_at` 전에는 운영진의 출석 시작·종료·수동 변경과 회원의 출석 인증을 차단한다. 관리자 비공개 테스트도 출석 인증은 같은 시각 제한을 적용한다. 참가 신청·취소·명단 조회는 이 제한에 포함하지 않는다. 정기런·훈련·번개·이벤트 모두 동일하다.

클라이언트는 시작 시각까지 버튼을 비활성화하고 타이머와 화면 복귀 시각 검사로 해제한다. 기존 디자인을 유지하고 별도 서버 요청을 추가하지 않는다. 시작 시각 이후에도 기존의 출석 세션 시작/종료·참가 여부·계정 상태·4자리 번호 검증은 유지한다. 브라우저 시계가 부정확해도 DB의 `now()`가 최종 판정한다.

배포 전에 `supabase/migrations/032_attendance_start_time.sql`을 적용한다. 기존 출석 기록과 RLS 정책은 수정하지 않는다. DB 적용이 누락되면 UI만으로 직접 RPC 호출을 차단할 수 없으므로 SQL 적용이 필수다. 원격 DB 적용은 이 작업에 포함되지 않았다.

`npm run test:attendance-start-db`: 네 종류의 일정에서 시작 전 open/check/manual/close 및 관리자 테스트 거부와 정확한 시작 시각 및 시작 후 정상 처리를 PostgreSQL로 검증한다(32개).
