# 정기런 양식의 페이스 그룹

013 이후 `014_regular_template_pace_groups.sql` 전체를 SQL Editor에서 실행한다. 기존 양식에는 빈 그룹 목록이 추가되고, 기존 일정과 참가 기록은 바꾸지 않는다. 반복 실행 가능하다.

**일정 → 정기런 양식 관리 → 수정 → 기본 페이스 그룹 → 그룹 추가 → 양식 저장**에서 페이스와 거리를 등록한다. 페이스는 30초 단위, 거리는 5km 단위이고 같은 페이스·거리 조합은 중복할 수 없다. 양식당 최대 20개이다.

**일정 만들기 → 정기런 양식 선택 → 기본 정보 불러오기 → 날짜·시간 입력 → 일정 생성**을 실행하면 양식 그룹이 새 일정의 `pace_groups`에 별도 UUID로 복사된다. 이후 그룹 추가는 기존 일정 상세 화면에서 가능하다.

복사는 일정 INSERT 트리거에서 실행해 일정과 그룹을 같은 트랜잭션으로 저장한다. 그룹 삽입이 실패하면 일정도 롤백한다. 번개런·훈련·이벤트에는 복사하지 않는다. 양식 그룹 수정·삭제 및 기존 일정 수정은 이미 생성된 일정의 그룹이나 참가자 배정을 바꾸지 않는다. 기존 일정에 자동으로 그룹을 추가하는 기능은 아니다.

기존 양식의 그룹이 비어 있으면 새 일정에도 그룹이 생성되지 않는다. 이 경우 양식에 그룹을 먼저 저장하거나 기존 방식으로 일정에서 직접 추가한다.

단위 테스트 30개와 신규 DB 검사 22개가 통과했다. 잘못된 숫자·중복·개수 제한, 새 일정 복사, 기존 일정 유지, 비정기런 제외, 그룹 실패 시 전체 롤백과 삭제된 양식 차단을 확인했다. 운영 SQL 적용과 실제 계정 검증은 사용자가 진행한다.
