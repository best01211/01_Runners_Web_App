# 신규 회원 이용 흐름 개선 (2026-10-25)

## 적용 범위

- 홈: 내 신청 일정과 오늘 출석 바로가기, 신청이 없을 때 첫 러닝 안내.
- 일정: 전체 예정 일정 보기, 내 신청 표시, 내 신청 목록, 캘린더 날짜·필터를 유지하는 뒤로가기.
- 가입: 입력 규칙, 중복 확인, 비밀번호 표시, 실패 후 입력 유지, 이메일 확인·운영진 승인 단계 안내.
- 가입 상태: 비밀번호를 확인한 승인 대기 계정은 대기 화면으로 로그인. 회원 서비스 접근 권한은 기존대로 유지.
- 아이디 찾기: 가입 이메일의 본인 확인 링크로 자기 계정의 아이디·승인 상태만 확인. 미가입 이메일 여부는 공개하지 않음.
- 문의: 기본은 크루 운영진 안내·문의 문구 복사. `관리자 → 운영 설정 → 가입·승인 문의 링크`에서 HTTPS 또는 mailto 주소를 추가·삭제할 수 있음. 현재 실제 주소 없음.
- 참가: 신청·변경 저장·변경 취소·참가 취소를 분리. 같은 그룹을 다시 눌러도 참가가 취소되지 않음. 취소 기한 상시 표시.
- 출석: 신청과 출석의 차이, 출석번호를 받는 곳과 출석 시작 전 상태 안내. 내 출석·활동 내역과 상태 필터 제공.
- 알림: 신청한 일정의 변경·취소·새 공지, 내 댓글의 답글을 앱 안 알림함에 제공. 본인 알림만 조회·읽음 처리 가능.
- 일정 알림: 캘린더(.ics)에 저장, 1시간 전 알림 포함. 기기 캘린더의 알림 설정에 따라 동작. SMS·메일·브라우저 푸시를 발송하는 기능은 아님.
- 댓글: 내 댓글 수정, 답글, 실패 후 입력 유지, 변경 내용 재조회.
- 내 정보: 로그인 아이디 표시, 사진 삭제, 이름 사용 목적 안내.
- 대회 신청: 주자 신청과 운영진 선수 등록이 별도라는 안내. 수동 갱신에는 남은 대기 초 표시. 수집 주기는 기존 대회 시작 후 3분, 수동 갱신 최소 1분 유지.

제외 요청한 페이스 그룹 설명·짐 보관/포토 표현·장소 확인·활동 랭킹·신규 회원 랭킹·대회 예측/추적·응원 지점 기능은 변경 대상에서 제외. 참가 그룹 데이터·선택 권한·점수 집계 정책도 유지.

## 배포

1. Supabase에 `037_member_journey_notifications.sql` 적용. 알림 테이블, 본인 조회 RLS, 일정·댓글 알림 트리거가 추가됨. 기존 신청 기록의 과거 변경은 소급 알림하지 않음.
2. 앱 배포. 이메일 본인 확인에는 Supabase 이메일 발송 설정과 실제 서비스의 `/auth/callback?flow=account-help` 리다이렉트 허용 필요. 기존 callback 허용 와일드카드가 있으면 별도 추가 불필요.
3. 문의 링크는 없어도 사용 가능. 주소가 생기면 위 관리자 메뉴에서 저장. 비우고 저장하면 안내 버튼을 숨김.

이번 작업은 로컬 코드·검증까지이며 운영 DB 적용이나 배포는 수행하지 않음.

## 검증

- `npm run test:member-journey`: ICS 이스케이프·UTF-8 줄바꿈·알림, 문의 URL 검증·관리자 권한, 승인 대기 로그인 비밀번호 확인, 전체 예정 일정 페이지네이션, 개인 일정 필터, 알림 API 소유권·origin·로그인, 실제 PostgreSQL 호환 엔진의 알림 트리거·RLS.
- `npm run test:member-journey-browser`: 로컬 실제 React 컴포넌트/모의 API로 모바일 가입 재시도·입력 유지, 신청·변경·명시적 취소, 댓글 수정·답글, 프로필 사진 삭제, 알림 이동, 문의 링크 추가·숨김, 캘린더 필터·날짜를 유지하는 뒤로가기, 가로 넘침 검사. 운영 서비스 검증은 아님.
- 기존 `test:release`, `test:auth`, `test:schedule-overview-server`, `test:dashboard-streaming`, `test:page-context`, `test:tracking-ui-browser`, TypeScript, ESLint, 프로덕션 빌드 확인.
- 브라우저 검사용 임시 의존성은 기존 지도/DB 검사와 동일하게 `.test-output/map-qa`, `.test-output/sql-qa` 사용.
