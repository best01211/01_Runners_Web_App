# 간결한 크루 홈 (2026-10-25)

홈을 다음 세 가지로 정리했습니다.

1. 내 다음 러닝: 오늘 신청 일정 우선, 없으면 가장 가까운 신청 일정 하나. 오늘 미인증이면 출석 인증 버튼, 인증 후에는 신청 정보 버튼. 추가 신청은 개수와 내 일정 링크로 안내.
2. 내 신청 일정·내 출석 내역·내 알림 바로가기.
3. 다가오는 크루 일정 최대 두 개: 제목·시간·유형·모집 상태만 요약하고 전체 일정 링크 제공.

큰 소개 배너, 역할·승인 뱃지, 홈 순위·점수·출석 통계, 주 메뉴와 겹치는 기능 설명 카드를 제거했습니다. 상세 활동·랭킹 기능은 해당 화면에서 계속 제공합니다. 운영진의 가입 승인·관리 링크는 접힌 ‘크루 운영’에 유지했습니다. 홈은 전체 랭킹을 조회하지 않습니다.

DB 마이그레이션은 필요하지 않으며 앱 배포로 반영됩니다. 로컬 코드만 수정했고 Git 업로드·운영 배포는 수행하지 않았습니다.

검증: TypeScript, 변경 파일 ESLint, `test:dashboard-streaming`(랭킹 쿼리 없이 일정 표시), `test:home-browser`(360/390/1280px; 일반·신청 없음·오류·긴 이름/제목·출석 완료·관리자·이용 제한; 출석 바로가기·일정 두 개 제한·운영 메뉴 접힘·가로 넘침).

브라우저 검사는 실제 홈 컴포넌트에 고정 데이터를 넣은 로컬 검사이며 운영 서비스 검증은 아닙니다. 기존 테스트용 `.test-output/map-qa`의 esbuild/Playwright를 사용합니다.
