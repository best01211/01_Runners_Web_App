# 회원 관리와 관리자 운영 설정

- 크루 관리 `/admin`: 회원 관리(조회), 시즌 관리(생성·기간·공개 여부·현재 시즌 지정 통합), 정기런 양식 관리(별도 탭), 활동 점수 환경 설정.
- 관리자 · 운영 설정 `/admin/operations`: 실제 관리자만 서비스 점검·접속·기능 제한 설정. 이전 `?tab=operations` 주소는 새 화면으로 이동.
- 회원 목록: 전체 / 관리자 / 운영진 / 회원 / 게스트. 전체는 관리자를 제외한 모든 계정(승인 대기·탈퇴 포함)을 표시하고 등급별 탭은 해당 등급만 표시한다. 관리자 탭은 관리자에게만 표시한다. 회장·부회장·일반 운영진에게는 관리자 계정이 서버 조회 단계부터 제외된다.
- 목록에는 이름·닉네임·삭제 여부·역할만 표시. 회원을 누르면 역할·활성 상태 설정이 펼쳐진다. 상세 보기는 별도 `/admin/members/[userId]` 페이지로 이동하며 회원 목록으로 돌아갈 수 있다.
- 기존대로 관리자·회장만 변경 가능. 일반 운영진·부회장은 조회 전용. 회원 상세 페이지에서도 계정 활성 설정 가능. 자기 자신과 관리자 등급 보호, 삭제 사전 확인 절차 유지.
- 상세 보기: 연락처·생년월일·승인 및 계정 상태·페이서·랭킹 설정·가입 정보와 전체 기간 출석 집계 및 이력. 비밀번호·인증 토큰·출석 번호는 제공하지 않는다.
- 전체 탭에서 회원을 선택하여 출석 CSV 다운로드(한 번에 최대 500명). 조회 권한이 있는 회원만 다운로드 가능하며 서버에서도 대상별 권한을 재검사한다.
- CSV는 한국 시간, Excel용 UTF-8 BOM, 수식 방지 처리를 적용. 기록 없는 회원도 기록 없음 행으로 포함. 취소·삭제 일정 이력은 별도 상태로 포함하며 화면 집계에서는 제외한다.
- 탈퇴하여 계정이 보존된 경우 미삭제·탈퇴 계정으로 표시한다. 영구 삭제된 계정은 프로필이 존재하지 않아 목록에 표시할 수 없다.

## 확인 방법
1. 관리자: 운영 메뉴의 두 화면이 분리되어 있고 크루 관리에 운영 설정 탭이 없는지 확인.
2. 전체·관리자·운영진·회원·게스트 탭에서 계정 분류 확인.
3. 회원 행 클릭 → 역할·활성 상태 변경 → 상세 보기에서 연락처와 출석 이력 확인.
4. 전체 탭에서 회원 여러 명 선택 → 출석 CSV 다운로드 → Excel에서 한글과 출석 상태 확인.
5. 일반 운영진·부회장: 관리자 숨김, 조회 전용, 운영 설정 직접 접속 불가 확인.

이번 회원 관리 변경에는 추가 SQL 실행이 필요 없다. 기존 활동 기능의 SQL 021·022 적용 여부는 별도 확인한다.

검증: `node scripts/test-admin-directory.mjs`, `node scripts/test-member-directory.mjs`, `npm run test:release`, `npm run lint`, `npm run build`. 브라우저 검증은 실제 컴포넌트와 가상 데이터로 수행하며 운영 DB 변경·다운로드를 실행하지 않는다.

정기런 양식 관리는 `/admin?tab=templates`로 분리했다. 기존 `/schedules/templates` 주소는 새 탭으로 이동하며 일반 운영진·부회장을 포함한 기존 양식 관리 권한은 유지한다.

정기런 양식 탭은 목록만 표시한다. 추가는 `/admin/templates/new`, 수정은 `/admin/templates/[templateId]/edit`에서 처리하며 저장 완료 시 목록으로 복귀한다. 양식 관리에서는 일정 생성 버튼을 제공하지 않는다. 기존 사진·그룹·양식 삭제 API는 유지한다.
