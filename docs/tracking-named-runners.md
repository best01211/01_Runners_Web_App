# 이름 직접 입력으로 선수 등록

선수 등록에서 회원 목록을 선택하지 않고 이름·배번호·그룹을 입력한다.
동명이인은 서로 다른 선수로 등록할 수 있으며, 같은 종목의 배번호는 중복할 수 없다.
기존 선수 수정은 등록 구분에서 대상을 선택한다. 출발 이후 또는 계측 기록이 생긴
선수의 수정 잠금은 유지한다. 기존 회원 연결과 계측 기록은 보존한다.

033 이후 `supabase/migrations/034_tracking_named_runners.sql`을 적용하고 앱을 배포한다.
034는 회원 연결을 선택 항목으로 바꾸고 이름 직접 등록·수정, 조회 RLS,
회원 계정 없는 선수의 자동 계측 저장을 지원한다. 재실행할 수 있다.
기존 033의 회원 이름만 사용하는 등록 정책을 대체한다.

앱 조회도 저장된 선수 이름을 우선 사용하며 회원 연결이 없는 선수를 포함한다.
등록된 활성 선수가 관리자 계정에 연결되어 있다는 이유로 일반 회원 화면에서
제외되던 조건을 제거했다. 계측 수집은 종목과 배번호로 연결하고 이름은 비교하지 않는다.

검증은 `npm run test:tracking`, `node scripts/test-tracking-staff-api.mjs`,
`node scripts/test-tracking-timing-database.mjs`로 실행한다.
테스트 DB는 메모리 DB이며 운영 DB를 수정하지 않는다.
