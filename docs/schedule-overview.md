# 일정 목록·홈·캘린더

- 홈: 정기런·훈련·이벤트만 표시. 번개런은 러닝 일정에서 조회.
- 다가오는 일정: 정기런·훈련 각각 가장 가까운 미종료 1건. 이벤트·번개런은 현재부터 한 달 이내 모두 조회하며 개수 제한을 두지 않음.
- 한 달은 한국 시간 기준 다음 달 같은 날짜·시각까지. 해당 날짜가 없으면 말일로 조정. 진행 중 일정은 종료 전까지 포함하며 종료·취소 일정은 제외.
- 카드: 제목, 연·월·일·요일, 시작 시간, 신청 마감 일시, 위치, 모집 상태·종료 여부, 러닝 유형 표시.
- 러닝 일정: 다가오는 일정 / 지난 일정 / 캘린더 보기와 전체·정기런·훈련·이벤트·번개런 유형 필터.
- 캘린더는 한국 시간의 일정 시작 날짜를 기준으로 표시. 월 이동·이번 달·날짜 선택·유형 필터 제공. 선택 날짜의 일정 카드를 하단에 표시하며 지난·취소 일정도 상태와 함께 확인 가능.
- 조회는 페이지 단위로 이어 읽어 Supabase 기본 행 제한으로 일정이 누락되지 않도록 처리.
- DB 스키마·참가·취소·권한 로직 변경 없음. 추가 SQL 불필요.

검증: 일정 선택·말일·윤년·한국 시간 경계·종료 상태·1,200개 이벤트 테스트 포함 `npm run test:release`, 린트·빌드. UI는 실제 컴포넌트를 가상 데이터로 검증.
