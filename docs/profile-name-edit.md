# 내 이름 수정

018까지 적용한 뒤 Supabase SQL Editor에서 `supabase/migrations/019_profile_name_edit.sql` 전체를 실행하고 웹을 새로고침한다. 기존 회원의 이름은 SQL 실행만으로 변경되지 않는다.

- 내 정보에서 이름을 2~50자로 수정할 수 있다.
- 입력란 아래에 실제 이름과 다르면 불이익을 받을 수 있다는 안내를 표시한다.
- 이름이 바뀐 상태에서 프로필 저장을 누르면 확인 창이 열린다. ‘취소’ 또는 Esc는 저장하지 않고 창을 닫는다. ‘확인하고 저장’을 누르면 프로필 저장을 진행한다.
- 이름이 그대로라면 이름 변경 확인 창은 띄우지 않는다.
- API와 DB 함수도 이름 변경 경고 확인 여부를 검사한다. 다른 회원의 이름이나 본인 권한을 함께 변경하는 것은 허용하지 않는다.
- 저장 후 상단 계정 표시도 다시 조회한다. 닉네임을 쓰는 영역은 기존대로 닉네임을 우선한다.
- 내 정보 수정 점검·계정 정지·회원 승인 등 기존 접근 제한을 유지한다.

실제 이름인지 자동 판별하거나 자동 제재하는 기능은 추가하지 않는다. 경고 확인과 이름 저장만 처리한다.

## 확인

1. 이름 변경 후 저장하면 경고 창이 열리는지 확인한다.
2. 취소하면 입력 내용은 유지되고 저장된 이름은 바뀌지 않는지 확인한다.
3. 다시 저장해 ‘확인하고 저장’을 선택하고 새로고침 후 이름을 확인한다.
4. 이름을 그대로 두고 다른 항목만 저장하면 이름 경고가 나타나지 않는지 확인한다.

로컬 DB 테스트 `npm run test:profile-name-db`: 확인 없는 변경 거부, 입력값 검증, 본인 계정 한정, 점검 중 차단, 제한·정지 계정 처리를 포함한 20개 검사 통과.
