# 출석번호 4자리와 참가 버튼 개선

Supabase SQL Editor에서 supabase/migrations/020_four_digit_attendance.sql 전체를 실행한다. 016 이후 기존 출석 함수의 권한·참가·잠금·출석 로직을 유지하며 생성 번호를 1000~9999로 변경하고 검사 형식은 숫자 4자리로 제한한다. 프론트엔드와 API도 같은 형식을 검사한다.

실행 중인 출석 세션의 6자리 번호는 뒤 4자리로 변경된다. 출석 기록과 잠금은 유지한다. SQL 실행 후 운영진 화면을 새로고침하고 새 4자리 번호를 안내한다. 종료된 일정의 과거 번호는 보존된다. 이 SQL은 운영 DB에서 아직 실행하지 않았다.

그룹 변경은 진한 테두리, 참가 취소는 붉은 테두리·연한 빨강 배경으로 표시한다. 비활성 버튼도 읽을 수 있게 유지하며 그룹 잠금·계정 제한·취소 기한 안내를 표시한다. 신청·취소 조건은 변경하지 않는다.

ESLint·테스트 45개·타입 포함 빌드 통과. 가상 데이터 모바일 화면에서 참가 완료 버튼 배치 확인. 실제 DB 4자리 생성·인증은 SQL 적용 후 운영진/회원 계정으로 확인해야 한다.
