# 추적 이벤트 삭제

관리자와 회장에게 추적 목록·상세의 이벤트 삭제 버튼을 제공한다. 일반 운영진·부회장·회원에게는 제공하지 않으며 DELETE API에서도 canAdminister 권한과 동일 출처를 검사한다.

삭제 확인 후 tracking_races.status를 기존 archived 상태로 변경한다. 목록·상세·조회 API 및 기록 쓰기 RPC의 기존 active 조건에 의해 접근과 추가 기록을 차단한다. 선수·체크포인트 기록은 보존되므로 영구 파기가 아니다. 추가 마이그레이션은 필요 없다.

검증: node scripts/test-tracking-deletion.mjs로 실제 DELETE 핸들러의 미인증·역할·계정 상태·출처·UUID·정상 보관·재요청·DB 실패·미존재를 모의 DB로 확인했다. ESLint와 빌드 통과. 가상 데이터 화면에서 버튼 배치를 확인했으며 운영 DB의 실제 이벤트는 삭제하지 않았다.

직접 확인: 관리자 로그인 → 추적 목록 → 테스트 이벤트의 이벤트 삭제 → 취소하면 유지 → 다시 삭제 후 확인하면 목록에서 사라짐. 이전 상세 주소로도 조회되지 않는지 확인한다.
