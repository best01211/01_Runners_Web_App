# 좁은 화면 배치 점검 (2026-10-15)

## 범위와 결과

- 실제 로그인 화면: 360px에서 가로 넘침 없음.
- 관리자·일정 생성/참가·내 정보·점검 팝업의 실제 컴포넌트를 가상 데이터로 렌더링해 확인.
- 320·360·390·768·1280px에서 4종 화면, 총 20가지 배치의 가로 넘침 없음.
- 390×360의 낮은 화면에서 팝업과 확인 버튼이 화면 안에 표시됨.
- 긴 이메일·시즌 이름과 날짜 입력창을 포함해서 확인.

로그인 뒤 전체 페이지를 실제 계정으로 조작한 테스트가 아닌 컴포넌트 배치 검증이다. 휴대전화 키보드·네이티브 날짜 선택창·실제 사진 선택·실제 메일 인증은 배포 후 실기기에서 확인한다.

## 수정

- 점검 시작·종료 안내 시각을 세로 배치하여 날짜 입력창의 잘림 완화.
- 공통 입력창이 좁은 영역 안에서 줄어들도록 최소·최대 너비 조정.
- 회원 이메일·긴 일정 및 댓글 내용의 줄바꿈 처리.
- 시즌 이름과 기간을 좁은 화면에서 세로로 배치하고 날짜 입력에 항목명 추가.
- 서비스 설정 체크박스의 선택 영역과 공통 입력창 높이를 최소 44px로 확보.
- 주요 페이지 제목과 메뉴가 좁은 화면에서 다음 줄로 배치되도록 조정.
- 낮은 화면에서 긴 점검 팝업을 내부 스크롤할 수 있도록 처리.

## 다시 확인하기

`node scripts/preview-responsive.mjs`를 실행하고 `http://localhost:3101`을 연다. 개발자 도구에서 화면 너비를 변경한다. 이 서버는 가상 데이터로 화면만 렌더링하며 로그인·DB 변경·실제 제출 기능은 없다. 종료는 Ctrl+C.

린트 및 프로덕션 빌드로 정적 검증을 수행한다. DB SQL 추가 적용은 필요 없다.
