# 2001 Runners UI 디자인

## 방향과 참고

제공된 2001 로고의 굵기와 기울기를 중심으로 흑백, 따뜻한 흰 배경, 얇은 구분선으로 구성했다. 반복적인 둥근 카드와 장식용 영문 문구를 줄이고 크루 게시판과 대회 기록표의 형태를 적용했다.

공식 사이트를 직접 비교한 디자인 해석:
- Bandit Running: https://banditrunning.com/ — 강한 흑백 대비와 큰 타이포그래피를 참고.
- Tracksmith: https://www.tracksmith.com/na/ — 러닝 커뮤니티 중심의 정보 우선순위를 참고.
- District Vision: https://districtvision.com/ — 여백과 절제된 구분 방식을 참고.

외부 사진이나 브랜드 자산은 사용하지 않았다. 사용자 제공 로고 원본은 public/branding/01runners-logo.png에 보관하며, 바깥 여백과 어두운 배경 표시는 CSS로만 처리한다.

## 적용

- 공통: PC 상단 메뉴, 모바일 하단 메뉴, 운영 권한별 메뉴, 얇은 테두리와 일관된 버튼·입력창.
- 홈: 공식 로고와 다음 러닝을 중심으로 배치. 이후 일정과 활동 링크를 목록으로 구성.
- 일정: 날짜와 모집 상태를 먼저 확인하는 목록. 홈에는 실제 다가오는 일정을 표시.
- 랭킹: 상위 3명 장식 카드를 없애고 순위·이름·출석·점수를 기록표로 표시. 현재 시즌 우선 선택과 전체 시즌 선택 유지.
- 로그인·가입: 공식 로고와 단정한 회원 폼. PC 로그인은 흑백 포스터 구성, 모바일은 간결한 한 열 구성.
- 내 정보·운영 관리·추적: 공통 색상과 간격, 입력창·정보 구역 스타일 적용.

## 검증

2026-10-15: 실제 컴포넌트의 가상 데이터 미리보기로 홈·일정·랭킹·관리·일정 생성·내 정보 6개 화면을 320/390/768/1024/1440px에서 확인했다. 30개 조합 모두 문서 가로 넘침이 없었다. 실제 개발 서버 로그인 화면도 PC와 모바일에서 확인했다.

릴리스 테스트 40개, ESLint, 프로덕션 빌드 통과. 스타일 파일을 합친 뒤 개발 서버의 새 CSS 파일 감지 문제도 해소했다. 인증 뒤 실제 계정별 동작 및 실기기 터치는 별도 확인 대상이다.

기능 로직과 DB 정책은 유지하며 이번 디자인 적용에 추가 SQL은 필요하지 않다. 미리보기 일정·이름·점수는 가상 데이터이며 운영 DB에 저장하지 않는다.

## 러너블 참고 가이드 적용 및 사용자 색상 수정 — 2026-10-15

사용자 지시에 따라 검정과 흰색이 기본이며 파랑은 사용하지 않는다. 주요 버튼과 현재 메뉴는 #18181B, 배경 #FAFAFA, 카드 #FFFFFF, 경계 #E4E4E7이다. 핑크 #BE185D / 연한 배경 #FDF2F8은 번개런과 본인 랭킹 표시, 초록 #166534 / 연한 배경 #F0FDF4는 정기런·모집 중·승인 상태에 사용한다. 상태는 항상 텍스트도 함께 표시한다.

홈은 인사 → 다음 러닝 → 회원 상태 → 4개 바로가기 → 이후 일정과 활동 링크 순서다. PC에서는 다음 러닝과 회원 정보를 2:1로 배치하고 모바일에서는 한 열로 배치한다. 제공 로고는 공통 헤더와 로그인에서 유지한다. 사진은 추가하지 않는다.

카드 모서리 16px, 입력창·버튼 10px, 주요 조작 높이 48px, 입력값 16px. 768px 태블릿, 1024px PC, 1440px 와이드 기준을 사용한다. 1024px 미만은 하단 내비게이션을 표시하고 안전 영역 여백을 확보한다. 루트는 기존 proxy의 인증·승인·점검 검사를 거쳐 대시보드로 이동한다.

원본 참고: https://runable.me/ — 모바일 중심 탐색과 기능 바로가기 구조를 참고했으며 이미지·로고·문구를 복제하지 않는다.

검증: 릴리스 테스트 40개, ESLint 및 프로덕션 빌드 통과. 실제 컴포넌트를 가상 데이터로 렌더링한 홈·일정·랭킹·관리·일정 생성·내 정보의 320/390/768/1024/1440px 30개 조합에서 가로 넘침 없음. 모바일 랭킹과 PC 홈을 시각 확인했다. 실제 로그인 계정별 기능 테스트와 실기기 터치 확인은 별도이다.
