# 모바일 홈 1차 개선 — 2026-10-15

## 범위
사용자가 승인한 크루 홈, 공통 헤더·하단 메뉴와 필요한 스타일만 수정했다. API·인증·권한·Supabase·DB 스키마는 변경하지 않았다. 다른 화면의 전면 개편은 후속 단계이다.

## 변경
- 홈: 인사·역할·승인 상태 → 다음 러닝 → 이후 일정 → 크루 활동 → 권한별 운영 링크.
- 큰 회원 소개 카드·중복 아이콘 바로가기 제거. 빈 일정은 내용에 맞는 높이로 표시.
- 다음 러닝의 날짜는 한국어 월·일·요일, 시간·장소·정원·마감과 일정 보기 링크를 제공. 목록의 기존 날짜 표현은 유지.
- 모바일 배경 #F8F9FA, 표면 #FFFFFF, 주요 글자 #17191C, 경계 #E9EDF1. 작은 보조 본문은 대비를 위해 #69717B 사용. 핑크·초록 상태 표시는 유지.
- 모바일 홈 좌우 20px, 구역 간격 28px, 카드 안쪽 20px, 모서리 16px. 홈 최대 너비 720px.
- 하단 메뉴 5개 전체 이름 복원. 아이콘 21px, 활성 상태 굵기·표시선, 각 링크 높이 48px. safe-area 패딩과 viewport-fit=cover 설정.
- 이전 홈·대표 일정·내비게이션 CSS 선택자를 제거하고 통합. 해당 구역에 !important를 추가하지 않음.
- 폰트는 기존 공급 방식 유지. Pretendard 다운로드·라이브러리 설치 없음.

## 확인
실제 컴포넌트를 정적 가상 데이터로 렌더링하여 8개 화면 상태(기본 홈·빈 홈·조회 실패 및 제한 계정·긴 이름/제목/장소 및 관리자 홈·일정·랭킹·내 정보·관리)를 320/360/390/430/768/1024/1440px에서 확인. 총 56개 조합에서 가로 넘침 없음.

844px 높이 기준 일반 홈의 다음 러닝 카드 하단은 360px에서 약 568px, 390·430px에서 약 539px로 첫 화면에 표시된다. 이후 일정 빈 안내 높이는 약 46px. 하단까지 스크롤하면 마지막 활동 링크가 고정 메뉴 위에 표시되는 것을 확인했다. 실제 휴대전화 Safari의 안전 영역·터치·키보드는 배포 후 확인 대상이다.

ESLint·릴리스 테스트 40개·TypeScript 포함 프로덕션 빌드 통과. 운영 DB에 쓰거나 실제 계정으로 신청·취소를 수행하지 않았다.

## 홈 개인 활동 현황

모바일(1024px 미만)에서 중복 크루 활동 메뉴를 숨기고 개인 활동 현황을 제공한다. PC의 크루 활동 링크는 유지한다. 다음 러닝과 이후 일정, 권한별 운영 메뉴도 유지한다.

현재 사용자의 UID를 서버에서 전달하여 loadRanking의 동일한 시즌·점수·순서 규칙으로 순위와 점수를 계산한다. 현재 시즌이 없으면 전체 시즌을 사용한다. 최소 활동 미달이면 순위 없이 쌓인 점수와 출석을 제공한다. 관리자·랭킹 제외 등은 순위와 점수를 부여하지 않고 본인 출석 기록만 표시한다. 출석률은 기존 랭킹과 동일하게 (출석+지각)/집계 기록 수이며 취소·삭제 일정과 시즌 밖 기록을 제외한다. 집계 기록이 없으면 출석률을 0%로 오인하지 않도록 —로 표시한다.

랭킹 조회 실패는 일정 조회와 분리하여 안내한다. DB/API 변경 없음. 단위 테스트 4개 추가, 총 릴리스 테스트 44개·ESLint·빌드 통과. 가상 데이터 기본·빈 상태·오류 화면의 360/390/430/1024px 12개 조합에서 가로 넘침과 모바일 메뉴 숨김 확인. 실제 운영 계정 데이터는 사용자 확인 대상이다.

## UI/UX 고도화 Phase 2 — 홈 정보 계층

사용자 승인 범위인 홈·대표 일정 표시·필요한 스타일만 변경했다. 다음 러닝 → 내 활동 현황 → 이후 일정 순서로 배치했다. 대표 일정은 제목을 먼저 표시하고 한국어 날짜 블록·시간·장소·상태·모집 정보·상세 이동 순서로 구성했다. 모집 상태의 계산과 신청 관련 로직은 변경하지 않았다. 기존 일정 목록의 JSX 표현은 유지한다.

모바일은 한 열, PC(1024px 이상)는 최대 1080px의 일정/개인 활동 두 열 구성이다. 모바일 중복 메뉴 숨김과 기존 권한별 운영 링크를 유지했다. 개인 활동 카드 내부 여백과 구역 간격을 조정해 390×844px 가상 데이터 화면에서 개인 출석 현황까지 첫 화면에 표시된다. 긴 정보가 있으면 필요한 만큼 늘어나며 강제 자르지 않는다.

검증: 기본·빈 상태·오류·긴 텍스트 홈과 일정·랭킹을 320/360/390/430/768/1024/1440px에서 확인, 42개 조합 가로 넘침 없음. PC와 모바일 화면 시각 확인. 실제 localhost:3000에서 최신 대표 일정/PC 그리드 CSS가 전달되는 것을 CSSOM으로 확인했다. 로그인된 계정으로 신청·취소를 수행한 검증은 아니며 운영 데이터는 변경하지 않았다.

ESLint·릴리스 테스트 44개·TypeScript 포함 빌드 통과. 남은 항목: 실제 휴대전화 터치·키보드·안전 영역, 로그인 계정별 사용자 흐름. 일정 목록의 영문 날짜 등 다른 화면 전면 적용은 홈 승인 후 Phase 4에서 진행한다.

### 홈 시각적 밀도 보완

검정 날짜 블록·강조된 시간·검정 상세 이동 영역으로 대표 일정의 시각적 중심을 만들었다. 개인 활동은 #FFF6FA의 연한 핑크 표면과 큰 순위·점수, 흰 출석 정보 영역으로 구분한다. 데이터가 없을 때의 — 표시와 기존 조건은 유지한다. PC는 최대 1000px과 1.3:1 열 비율로 빈 공간을 줄였다. 이미지·기능·API·계산 로직은 추가하거나 변경하지 않았다.

가상 데이터 홈 4개 상태 × 7개 화면 너비, 28개 조합에서 가로 넘침 없음. PC·모바일 시각 확인 및 실제 개발 서버 최신 CSS 전달 확인. ESLint·타입 포함 프로덕션 빌드 통과. 실기기와 로그인 계정별 조작은 별도 확인 대상이다.
