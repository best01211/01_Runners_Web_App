# 알림 조회 오류와 필수 DB 설정

알림 기능은 `supabase/migrations/037_member_journey_notifications.sql`의 테이블·권한·트리거가 필요합니다. 038·039는 일정 삭제 함수만 수정하므로 037을 대신하지 않습니다. 사용자가 이전에 제공한 운영 DB의 FK 진단 CSV에는 `member_notifications`가 없었습니다. 현재도 누락되어 있다면 Supabase SQL Editor에서 037 전체를 실행한 뒤 알림 화면을 다시 시도합니다. 기존 038·039 적용 후에도 037을 실행할 수 있으며, 삭제 함수는 덮어쓰지 않습니다. 과거의 변경·댓글 알림은 소급 생성하지 않습니다.

앱은 테이블 누락(42P01/PGRST205), 구조·관계 캐시 불일치, 권한 오류를 구분해서 안내합니다. 실패를 알림 0개로 처리하지 않으며 조회 중·조회 실패·실제 0개를 구분합니다. DB 오류는 성공으로 감추지 않고 재시도할 수 있습니다.

검증: DB 설정 오류별 API 응답, 본인 조회·읽음 처리 제한 및 알림 트리거·RLS, 브라우저에서 설정 누락 오류 → 0개 미표시·모두 읽음 비활성 → 재시도 성공, TypeScript와 변경 파일 ESLint. 운영 DB 적용은 수행하지 않았습니다.
